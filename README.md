# 🌊 Shahad Al-Johani — Personal Portfolio

A modern, responsive, and animated **developer portfolio website** built with **React + Tailwind CSS**, designed to showcase my skills, projects, achievements, and career journey in software engineering, cloud computing, and UI/UX design.

---

## ✨ Overview

This portfolio represents my personal brand — blending creativity, interactivity, and clean code aesthetics.

- 🎨 Built using **React**, **Tailwind CSS**, and **Framer Motion**
- ☁️ Deployed on **Netlify**
- 🧠 Features dynamic animations, custom components, and reusable sections
- 💬 Displays real projects connected to **Firebase**


---

## 🧩 Tech Stack

| Category | Tools & Technologies |
|-----------|----------------------|
| **Frontend** | React, JavaScript, Tailwind CSS |
| **Animations** | React Bits |
| **Backend / Database** | Firebase |
| **Design Tools** | Figma, Adobe Illustrator |
| **Deployment** | Netlify |
| **Version Control** | Git & GitHub |

---

## 🚀 Features

- 🧑‍💻 **About Me** — Showcasing background, passion, and career focus  
- 🧱 **Projects Section** — Displays my work, integrated with Firebase for data storage  
- 🪞 **Skills Section** — Animated tech logos categorized by Frontend, Cloud, and Design  
- 🎓 **Achievements & Certificates** — Custom-designed cards with portfolio theme colors  
- 🌈 **Custom Backgrounds & Overlays** — Gradient and blurred backgrounds for a soft, modern aesthetic  
- 💫 **Animated Elements** — Floating icons and curved text loops using `React Bits`
